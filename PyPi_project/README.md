# Локальный репозиторий Python-пакетов (Private PyPI)

Полностью автономный, безопасный и автоматизированный локальный репозиторий Python-пакетов. Проект создан для устранения зависимостей от внешнего интернета, ускорения CI/CD процессов и гарантированной безопасности внутренних артефактов.

## Ключевые фичи
- **Zero-CLI для повседневных задач:** Вся работа (запуск, установка, публикация) осуществляется через интуитивные `.bat` скрипты с цветным визуальным фидбеком.
- **Жесткая безопасность:** Загрузка новых пакетов защищена паролем (`.htpasswd`), а установка настроена через `--no-index`, что физически блокирует обращение к публичному интернету.
- **Контроль качества (Quality Gate):** Перед публикацией каждый пакет автоматически проходит проверку безопасности (`bandit`) и unit-тесты (`pytest`).
- **Автоформатирование:** Интеграция `pre-commit` (black + isort) гарантирует, что в репозиторий попадает только код, соответствующий стандарту PEP-8.

## Технологический стек
- **Ядро:** Python 3.14, `pypiserver` (PEP 503 compatible)
- **Сборка и публикация:** `build`, `twine`
- **Безопасность и тесты:** `bandit`, `pytest`, `pre-commit`
- **UX:** Кастомные автоматизированные скрипты (`.bat`)

## Быстрый старт (Для разработчика)

Вам не нужно запоминать команды. Просто используйте готовые скрипты в корне проекта:

1. **Запуск сервера:** Дважды кликните на `START_HERE.bat`. Сервер запустится в фоне, и браузер автоматически откроет панель управления.
2. **Установка пакета:** Запустите `dev_install.bat`, введите имя пакета (например, `fastapi`). Скрипт установит его строго из локального кэша, заблокировав доступ в интернет.
3. **Публикация новой версии:** Запустите `build_and_upload.bat`. Скрипт сам повысит версию, прогонит тесты, проверит код на уязвимости и загрузит пакет на сервер.

## Администрирование
Для добавления новой библиотеки из внешнего интернета в локальный кэш используйте скрипт `admin_download.bat`. Он скачает пакет и все его транзитивные зависимости в защищенную папку `server/packages`.
