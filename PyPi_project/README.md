# Локальный репозиторий Python-пакетов (Private PyPI)

## Обзор
Данное решение представляет собой локальный репозиторий Python-пакетов, развернутый на базе `pypiserver`. Система предназначена для обеспечения независимости процессов разработки и CI/CD от внешних сетевых ресурсов, ускорения установки зависимостей и безопасного хранения внутренних артефактов компании.

## Ключевые возможности
- **Автономность:** Полная работоспособность при отсутствии доступа к сети Интернет или блокировке внешних репозиториев (pypi.org).
- **Безопасность:** Контролируемая среда для загрузки и распространения внутренних библиотек с защитой операции публикации паролем.
- **Производительность:** Сокращение времени сборки проектов за счет загрузки зависимостей из локальной сети.
- **Кэширование:** Возможность предварительной загрузки популярных публичных зависимостей для офлайн-использования.

## Технологический стек
- **Сервер:** `pypiserver` (совместимый с PEP 503 Simple Repository API).
- **Сборка пакетов:** `build` (PEP 517 / PEP 518).
- **Публикация:** `twine`.
- **Управление зависимостями:** `pip`.
- **Оркестрация:** Автозапуск через планировщик задач ОС (Windows Task Scheduler / shell:startup).

## Требования к окружению
- Python 3.8+
- Установленные пакеты: `pypiserver`, `passlib`, `twine`, `build`

## Развертывание и запуск

### 1. Инициализация аутентификации
Создание файла учетных данных для защиты операции загрузки (upload):
```bash
pip install passlib
python -c "from passlib.apache import HtpasswdFile; ht = HtpasswdFile('.htpasswd', new=True); ht.set_password('admin', 'mysecretpassword123'); ht.save()"
Запуск сервера
Запуск сервера с указанием файла аутентификации и директории хранения пакетов:
python -m pypiserver run -P .htpasswd -a . -p 8080 ./packages
Примечание: Флаг -P .htpasswd требует аутентификации для загрузки. Флаг -a . оставляет скачивание открытым для ускорения процессов внутри доверенной сети.

Инструкции по использованию
Публикация пакета (Upload)
Для загрузки собранного дистрибутива (.whl или .tar.gz) выполните:
python -m twine upload --repository-url http://localhost:8080 dist/*


При запросе используйте следующие учетные данные:
Username: admin
Password: mysecretpassword123

Установка пакета (Download)
Установка пакета из локального репозитория:
pip install --index-url http://localhost:8080/simple/ <имя_пакета>


Глобальная настройка клиента (Опционально)
Для автоматического использования локального репозитория по умолчанию в рамках проекта:
pip config set global.index-url http://localhost:8080/simple/
pip config set global.trusted-host localhost

Мониторинг и управление
- Веб-интерфейс для просмотра индекса доступных пакетов и их версий доступен по адресу:
http://localhost:8080
- Веб-интерфейс репозитория: http://localhost:8080
- Дашборд проекта: `server/dashboard.html` (открыть в браузере)

Безопасность
- Доступ на запись (upload) строго ограничен базовой HTTP-аутентификацией.
- Доступ на чтение (download) открыт для минимизации задержек в CI/CD пайплайнах внутри защищенного периметра сети.

Артефакты хранятся в изолированной директории ./packages, что обеспечивает сохранность данных при перезапуске сервиса.
