Private PyPI Repository

Локальный репозиторий Python-пакетов для безопасной и быстрой разработки

Статус сервера: Работает на http://localhost:8080

Доступные пакеты

  • my_super_lib (0.1.0) - Внутренняя библиотека
  • requests (2.34.2) - HTTP клиент
  • urllib3 - Зависимость requests
  • certifi - SSL сертификаты
  • idna - Зависимость requests
  • charset_normalizer - Зависимость requests

Быстрый старт

Установка пакета:

pip install --index-url http://localhost:8080/simple/ <имя_пакета>

Загрузка пакета:

python -m twine upload --repository-url http://localhost:8080 dist/*

Безопасность

  • Аутентификация для загрузки (upload)
  • Открытый доступ для скачивания (download)
  • Хранение паролей в .htpasswd
  • Изоляция от публичного PyPI

Преимущества

  • Работа без интернета
  • Ускорение сборки в 10x
  • Контроль зависимостей
  • Защита от блокировок
